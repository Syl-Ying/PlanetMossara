# Living World — Godot 4

为 M1/16GB Mac 制作的轻量3D生态模拟灰盒。全部画面使用 Godot 内置几何体生成，不需要下载美术素材。

## 已实现

- 可移动的第一人称3D场景。
- 24株发光芦苇、8只穴居食草兽和3只薄幕猎手。
- 觅食、进食、捕猎、逃跑、游荡和信号吸引行为。
- `Q` 释放营养诱导信号，吸引处于安全状态的食草兽。
- `E` 释放防御光，驱赶附近捕食者。
- 固定30Hz生态模拟和确定性随机种子。
- 实时HUD显示种群、逃跑状态、信号和模拟时间。
- 第一条完整生态谜题：把3只食草兽引入琥珀色花环，维持3秒打开活体门。
- 活体门后的青色信标构成本次灰盒的完成目标。
- 接近生物会自动记录观察，按 `Tab` 查看生态日志。
- 使用Compatibility渲染器，降低M1的运行负担。

## 运行

如果本机已经安装 Godot，可以双击 `launch_godot.command`；或者：

1. 下载并解压 Godot 4.7.2 Standard版。
2. 打开 Godot，选择 **Import**。
3. 选择本目录中的 `project.godot`。
4. 点击右上角运行按钮。

操作：

- `WASD`：移动
- 鼠标：观察
- `Q`：营养诱导
- `E`：防御光
- `Tab`：生态观察日志
- `Esc`：释放鼠标
