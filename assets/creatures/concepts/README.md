# 生物建模参考 v1

两张图由内置 image_gen 基于用户认可的效果图生成，作为造型参考，不是已完成的 3D 模型或严格可测量的工程投影。当前游戏模型未修改。

- approved_creature_direction.png：用户认可的整体美术方向。
- pigoid_turnaround_v1.png：正面、左侧面、背面、俯视肢体位置示意。
- sterq_serpent_turnaround_v1.png：正面、左侧面、背面、俯视结构示意。

## 建模结构约束

Pigoid：六足，前／中／后三对左右对称肢体；四片背甲沿脊柱中线单列排列，不是每侧四片。两根触须、柔软下垂口器、深色分趾足，无尾。骨白皮肤、灰绿背甲、细斑驳。先以侧面确定长度与肢体连接点，再以正／背面确定宽度；遮挡不可当作额外肢体。

Sterq Serpent：四足，前后两对；长尾从骨盆延伸。左右各一整片颈部感知膜，从头后沿颈部连接到肩部，不是独立翅膀。灰紫身体、暗酒红颈膜、细膜脉与椭圆孔洞。

## 三视图使用边界

生成图在局部轮廓、膜脉、孔洞数量、脚趾和遮挡细节上仍可能存在视图间差异，不能直接逐像素描摹为相互矛盾的网格。以上肢体数量和连接结构为硬约束；建模时用同一模型的正交相机统一比例与这些次级细节。原始效果图决定材质、气质和主要剪影。两种生物各自图内采用对齐基线；两张图不代表物种之间的实际体型比例。
